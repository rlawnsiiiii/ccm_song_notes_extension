# Changelog

## 1.0.0 — 2026-10-01
First release. Firefox desktop, local only.
- Live key and chord detection from the playing YouTube video (Web Audio, nothing uploaded).
- Analyse once, then play along: saved per video, bar chart with highlighting, tempo, sections
  (전주/절/후렴/프리코러스/브릿지/간주/후주), 전조 detection.
- Corrections: edit/split/merge chords, rename/split/merge sections; user edits survive re-analysis.
- Names ↔ numbers, transpose, simplified chords, A–B loop, playback speed.
- Korean lyrics view from the video's own captions, chords above lines.
- Reference search links, title cleanup, paste-in chart import aligned to the audio.
- 콘티 builder with per-song key, ChordPro export and A4 print; JSON backup/restore.
